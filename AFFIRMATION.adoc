== What this is, and how it works

network-outpost is a configuration-as-code home-network estate. The Core box
runs AdGuard Home in a digest-pinned Podman container, an `nftables`
default-deny firewall, chrony, CUPS and dynamic DNS. An optional Frontier box
adds shaping and exposed services. The repository holds POSIX shell scripts,
`nftables` rulesets, systemd units, a compose file, one image pin
(`images.lock`) and documentation. There is no compiled program and no test
suite. The evidence in this file is therefore static: shell syntax and lint,
`nftables` syntax checks, the repo's own doc-link checker, and a live
re-resolution of the image pin against Docker Hub.

== The epistemic contract

You may conclude that, at the anchor commit and at the stated time, each
command below produced the stated exit code and count on the stated toolchain.

You may *not* conclude that the estate boots, that the firewall behaves
correctly on a live host, that AdGuard Home blocks anything, or that the

=== The honest nuance you must not lose

* `nft -c` checks syntax and kernel acceptance inside an unprivileged user and
  network namespace. It does not prove the rules do what the comments say.
  Without `unshare -rn`, `nft -c` exits 1 with `Operation not permitted`. That
  failure is a missing privilege, not a ruleset error.
* Five of the 6 ShellCheck warnings are SC1007 on the `CDPATH= cd` idiom,
  which is deliberate. The sixth is SC2164 (`cd` without `|| exit`) in
  `bin/canary.sh` line 22. The 4 notes are SC1091: ShellCheck did not follow
  sourced files (`.env`, `images.lock`, `/etc/outpost/canary.env`).
* `bin/bump.sh --verify` asks the registry over the network. It is a claim
  about Docker Hub at 2026-10-07T10:5xZ, not a property of the commit.

== Reproduce it yourself

Run from the repository root at the anchor commit.

[source,bash]
----
sh bin/check-doc-links.sh; echo "rc=$?"     # expect rc=1, 33 dead refs
for f in bin/*.sh dependability/*.sh edge-shaper/*.sh host/setup.sh \
         host/ddns/*.sh host/ddns/*.in host/canary/*.in; do
  if head -1 "$f" | grep -q bash; then sh_=bash; else sh_=sh; fi
  "$sh_" -n "$f" || echo "BAD $f"           # expect no BAD lines
done
shellcheck -f gcc bin/*.sh dependability/*.sh edge-shaper/*.sh \
  host/setup.sh host/ddns/*.sh host/ddns/*.in host/canary/*.in
                                            # expect 6 warnings, 4 notes
for f in host/nftables.nft edge-shaper/nftables.nft \
         edge-shaper/monitoring-internal-only.nft; do
  unshare -rn nft -c -f "$f"; echo "$f rc=$?"   # expect rc=0 each
done
sh bin/bump.sh --verify; echo "rc=$?"       # expect rc=0 (network)
sh bin/bump.sh --check;  echo "rc=$?"       # rc=10 while v0.107.79 is newest
actionlint .github/workflows/*.yml          # expect 1 SC2086 info
----
